Easy Chem works like your games, so it runs from the prgm menu. It doesn't need the Python app. Send both files, then on the calculator press prgm, choose EASYCHEM, and press enter twice.

Files are sent exactly as they are, so you can use this for games too.

How to run a program on the calculator
  1. Press prgm (or apps) and open Python App.
  2. In the file list, move to the program (for Easy Chem: EASYCHEM) and press zoom for Run.
  3. If a program says it is missing a file, send all of its files again in RAM.
Not connecting?
  1. Use Chrome or Edge on a computer or Chromebook. Safari and Firefox can't talk to USB devices.
  2. Open this file straight from your computer (double-click it), or from a normal https web address.
  3. Close TI Connect CE if it is open. Only one program can use the calculator at a time.
  4. On Windows, the TI driver that comes with TI Connect CE can block the browser. If the calculator never shows up, use a Chromebook or Mac, or use the download buttons and send the files another way.
  5. Unplug the cable and plug it back in, with the calculator on the home screen.

Your files stay in this browser on this computer. Nothing is uploaded to the internet. Calculator connection uses the open-source ticalc-usb library (GPL-3.0). Its TI-84 Plus CE support is marked "beta".
